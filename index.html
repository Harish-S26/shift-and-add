Notes 2 · Why Shift-and-Add?


Binary multiplication is long multiplication with only two digits. Each multiplier bit is either 1 (add the multiplicand, shifted to that bit's position) or 0 (add nothing).


Shifting the multiplicand left doubles it each cycle, so bit i contributes M × 2i. An n-bit multiplier needs n iterations in the basic algorithm: 4 bits, 4 cycles. The product needs up to 2n bits: 8 here.









Fig. 4 · Datapath Architecture





MULTIPLICAND
Holds M; shifted left each cycle so it lines up with the next multiplier bit.


MULTIPLIER
Holds Q; shifted right so the next bit appears at Q₀.


ACCUMULATOR
Collects partial products; holds the final 8-bit product.


ADDER
Computes A + M when enabled.


Q₀
The control bit: 1 enables the add, 0 skips it.


COUNTER
Counts iterations; stops after 4.
